# O*NET: Work Activities

This folder contains the prepared O*NET 30.0 work-activities teaching dataset.
Each row describes a work-activity rating for an occupation; it is not an
individual worker's survey response.

## Files

- `data/work_activities.csv`: use with Python, R, or most other programs.
- `data/work_activities.dta`: use with Stata.
- `data/work_activities.xlsx`: use with Excel.

No teaching code is currently linked for this topic. Open the format appropriate
for your software and follow the accompanying course data-guide slides. Keep
any results in a separate `outputs/` directory rather than changing the input.

Keep generated figures and other results in `outputs/`; leave the data inputs unchanged.
